# Student Grade Calculator

A simple and responsive web-based Student Grade Calculator built using HTML, CSS, and JavaScript.

The application allows users to enter student information, subject names, and marks, then generates a detailed academic performance report.

---

## Features

- Student information management
- Custom subject names
- Marks entry for five subjects
- Automatic total marks calculation
- Average calculation
- Percentage calculation
- Grade calculation
- CGPA calculation
- Subject-wise grade points
- Subject-wise performance analysis
- Best subject identification
- Subject needing improvement identification
- Pass/Fail status
- Scholarship eligibility indication
- Overall performance analysis
- Visual performance percentage bar
- Result summary cards
- Result history using Local Storage
- Clear result history
- Form validation
- Dark mode
- Print result
- Download result as a text file
- Responsive design for mobile and desktop devices

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
